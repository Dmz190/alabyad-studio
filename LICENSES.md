## صورة الوجه / Portrait asset

`alabyad_portrait` صورة PNG بخلفية شفافة (1374×1145) مضمّنة داخل الملف وتخصّ صاحب المشروع.
تحمل الصورة بيانات اعتماد محتوى C2PA في مقطع `caBX`، وقد تُركت كما هي دون حذف.
ليست جزءًا من ترخيص الخطوط، ولا يشملها أي ترخيص مفتوح.

`alabyad_portrait` is a transparent PNG (1374×1145) embedded in the file and owned by the
project owner. It carries C2PA content credentials in its `caBX` chunk, left intact.
It is not covered by the font licence or by any open licence.

## الأشكال والرسومات / Shapes

الأشكال الـ 44 مرسومة كمسارات SVG داخل الكود نفسه (`defShape`) ولم تُؤخذ من أي مكتبة خارجية.
الزخارف هندسية عامة مستوحاة من أجواء المقاهي، دون ادعاء انتساب تاريخي.

The 44 shapes are SVG paths authored inline in the code (`defShape`). They come from no external
library. The ornaments are generic geometric forms; no historical attribution is claimed.

## المكتبات الخارجية / Third-party libraries

**لا توجد.** الملف لا يستخدم أي مكتبة JavaScript أو CSS خارجية، ولا يحمّل أي مورد عبر الشبكة.
كل شيء مكتوب يدويًا: محرك الرسم، كاتب PDF، كاتب مقطع pHYs داخل PNG، ومنقّي SVG.

**None.** The file uses no external JavaScript or CSS library and loads nothing over the network.
The rendering engine, the PDF writer, the PNG pHYs chunk writer and the SVG sanitiser are all
hand-written in the file.
